# Operating Systems Exercises (OSE)

Exercises from the Operating Systems course at the Hebrew University of Jerusalem, written in C++ on Linux.

| Folder | Topic | Status |
|--------|-------|--------|
| [`ex1/`](ex1/) | **User-level threads library**: a preemptive round-robin scheduler built on signals, timers and `sigsetjmp`/`siglongjmp` | Done |
| [`ex2/`](ex2/) | **Multi-threaded MapReduce framework**: map → sort → shuffle → reduce with `std::thread`, atomics and barriers | Done |
| [`ex3/`](ex3/) | Virtual memory: hierarchical page tables on top of simulated physical memory | In progress |

Each exercise folder has its own README that explains the design and how to build and run it.
